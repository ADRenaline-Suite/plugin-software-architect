# Strategy

Source: arc42 template 9.1. The file type is `strategy`. The whole manual is `/arch-arc42`.

## What it fixes

The quality goals, the constraints, and the chosen approach. Cite an accepted quality scenario and an accepted ADR when they exist. One diagram of the approach only if a source named its parts.

## How to do it

1. Read the folder the person named.
2. Follow the diagram rule in the skill when this section explains a picture.
3. Do not write the other arc42 sections in this file.

## Prompt

`/arch-arc42-strategy` Read the folder #folder. Write this section of #system in #language.

## Done

- The file uses the template fields. A gap is a line, not a guess.
- An explained section has a few plain sentences and one Mermaid diagram. The diagram is not called UML.
- The state is `accepted` only when no gap remains. Otherwise it is `proposed`.
