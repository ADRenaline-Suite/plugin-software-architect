# Glosario

Fuente: plantilla arc42 9.1. El tipo de archivo es `glossary`. El manual entero es `/arch-arc42`.

## Qué fija

Un término por concepto de esta arquitectura, con las palabras de las fuentes. No es el glosario de la interfaz ni el lenguaje del dominio. Sin diagrama.

## Cómo hacerlo

1. Lee la carpeta que la persona nombró.
2. Sigue la regla del diagrama del skill cuando esta sección explica una figura.
3. No escribas las otras secciones de arc42 en este archivo.

## Prompt

`/arch-arc42-glossary` Lee la carpeta #carpeta. Escribe esta sección de #sistema en #idioma.

## Done

- El archivo usa los campos de la plantilla. Un hueco es una línea, no una suposición.
- Una sección explicada tiene unas frases claras y un diagrama Mermaid. El diagrama no se llama UML.
- El estado es `accepted` solo cuando no queda hueco. Si queda, es `proposed`.
